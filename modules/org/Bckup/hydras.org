* Buffer Management Hydra

This section offers a focused menu for wrangling open work. It helps you switch, tidy, and organize what’s on your desk so nothing gets lost in the shuffle. The aim is to reduce context-juggling and keep momentum high. You get a clear sense of what’s open and where to go next.

#+BEGIN_SRC emacs-lisp :tangle yes
(defhydra hydra-buffer (:hint nil :color blue)
  "
^Buffer Management^
-----------------------------------------
_a_ : Kill all buffers + close sidebars
_o_ : Kill all other buffers
_u_ : Kill unmodified buffers
_s_ : Save buffer
_r_ : Revert buffer
_q_ : Quit
"
  ("a" my/kill-all-buffers-and-close-sidebars)
  ("o" my/kill-all-other-buffers)
  ("u" my/kill-unmodified-buffers)
  ("s" save-buffer)
  ("r" revert-buffer)
  ("q" nil "quit"))
#+END_SRC

* Org Mode Hydra

This gathers a compact set of tools for outlining, planning, and reviewing notes. It supports quick adjustments to structure so your ideas stay legible and alive. The focus is on keeping priorities visible and movement effortless. It encourages a rhythm of capture, organize, and act.


#+begin_src emacs-lisp :tangle yes

(use-package! hydra :demand t)
(require 'org)
(require 'org-agenda)
(setq hydra-lv t)

(defhydra hydra-org-agenda (:color blue :hint nil)
  "
┌─────────────────────────────── Org Agenda ─────────────────────────────────────────────────────────────┐
│ View   _d_: day   _w_: week   _m_: month     │ Navigate _n_: next  _p_: prev  _._: today  _g_: goto    │
│ Filter _/_: tag   _f_: follow _L_: log       │ Move     _>_: later _<_: earlier                        │
│ TODO   _t_: todo  _s_: sched  _D_: deadline  │ Priority _+_: ↑  _-_: ↓  _0_: none _1_: A _2_: B _3_: C │
│ Effort _E_: set   _C-e_: clear               │ Tags     _:_ set   _C-M-;_: clear                          │
│ Misc   _#_: cols  _G_: refresh  _x_: grid    │ File     _r_: refile _A_: archive                       │
│ Exit   _q_: quit                             │                                                         │
└────────────────────────────────────────────────────────────────────────────────────────────────────────┘
"
  ;; View
  ("d" org-agenda-day-view) ("w" org-agenda-week-view) ("m" org-agenda-month-view)
  ;; Navigate / Move
  ("n" org-agenda-next-line) ("p" org-agenda-previous-line)
  ("." org-agenda-goto-today) ("g" org-agenda-goto-date)
  (">" org-agenda-later) ("<" org-agenda-earlier)
  ;; Filter / modes
  ("/" org-agenda-filter-by-tag) ("f" org-agenda-follow-mode) ("L" org-agenda-log-mode)
  ;; TODO & scheduling
  ("t" org-agenda-todo) ("s" org-agenda-schedule) ("D" org-agenda-deadline)
  ;; Priority
  ("+" org-agenda-priority-up) ("-" org-agenda-priority-down)
  ("0" (lambda () (interactive) (org-agenda-priority 32)))  ; none
  ("1" (lambda () (interactive) (org-agenda-priority 65)))  ; A
  ("2" (lambda () (interactive) (org-agenda-priority 66)))  ; B
  ("3" (lambda () (interactive) (org-agenda-priority 67)))  ; C
  ;; Effort
  ("E" org-agenda-set-effort)
  ("C-e" (lambda () (interactive) (org-agenda-set-effort 0)))
  ;; Tags
  (":" org-agenda-set-tags)
  ("C-M-;" (lambda () (interactive) (org-agenda-set-tags nil)))
  ;; Refile / Archive
  ("r" org-agenda-refile) ("A" org-agenda-archive)
  ;; Misc
  ("#" org-agenda-columns) ("G" org-agenda-redo) ("x" org-agenda-toggle-time-grid)
  ;; Exit
  ("q" nil :color blue))
#+end_src

* Centaur Tabs

Tabs provide labeled anchors for juggling multiple pieces of work. They make it easy to jump between contexts without hunting. Grouping and order keep threads tidy and approachable. The visual design favors clarity so attention stays on content.

#+begin_src emacs-lisp :tangle yes
;; Requires :ui tabs (centaur-tabs) and :ui hydra
;; If you don't use the hydra module, install the `hydra` package yourself.

(use-package! hydra
  :after centaur-tabs
  :config
  ;; helpers
  (defun +tabs--goto (n)
    "Jump to visible tab N (1..9)."
    (interactive "p")
    (centaur-tabs-select-visible-nth-tab n))

  (defhydra +hydra-centaur-tabs (:color blue :hint nil)
    "
 Tabs  [_h_]← prev  [_l_] next →    Move  [_H_]←  [_L_]→       Groups  _[_ prev  _]_ next
 Misc  [_m_] local-mode  [_t_] toggle mode  [_x_] kill buf      Goto: _1_.._9_      [_q_] quit
"
    ;; basic nav (Doom wrappers also accept a count)
    ("h" +tabs:previous-or-goto)     ; prev (or goto count)
    ("l" +tabs:next-or-goto)         ; next (or goto count)

    ;; move current tab (centaur-tabs provides these)
    ("H" (call-interactively 'centaur-tabs-move-current-tab-to-left))
    ("L" (call-interactively 'centaur-tabs-move-current-tab-to-right))

    ;; group travel (only if available in your centaur-tabs version)
    ("[" (when (fboundp 'centaur-tabs-backward-group)
           (call-interactively 'centaur-tabs-backward-group)))
    ("]" (when (fboundp 'centaur-tabs-forward-group)
           (call-interactively 'centaur-tabs-forward-group)))

    ;; toggles & misc
    ("m" centaur-tabs-local-mode)    ; hide tabs in this buffer
    ("t" centaur-tabs-mode)          ; toggle global mode
    ("x" kill-this-buffer)

    ;; numeric goto (visible)
    ("1" (lambda () (interactive) (+tabs--goto 1)))
    ("2" (lambda () (interactive) (+tabs--goto 2)))
    ("3" (lambda () (interactive) (+tabs--goto 3)))
    ("4" (lambda () (interactive) (+tabs--goto 4)))
    ("5" (lambda () (interactive) (+tabs--goto 5)))
    ("6" (lambda () (interactive) (+tabs--goto 6)))
    ("7" (lambda () (interactive) (+tabs--goto 7)))
    ("8" (lambda () (interactive) (+tabs--goto 8)))
    ("9" (lambda () (interactive) (+tabs--goto 9)))

    ;; quit
    ("q" nil :exit t))

  ;; leader binding: SPC t t
  (map! :leader :desc "Centaur Tabs hydra" "t t" #'+hydra/centaur-tabs/body))

#+end_src

* Theme Selector Hydra

This is where you try on different visual moods with minimal effort. Switching is quick so you can match the time of day, task, or preference. Previews encourage exploration without commitment. You settle on what feels right and move on.

#+begin_src emacs-lisp :tangle yes
(defvar my/current-theme-index 0)

(defun my/theme-at-index ()
  (nth my/current-theme-index my/doom-themes-list))

(defun my/rotate-theme (direction)
  "Rotate themes and apply new one."
  (setq my/current-theme-index
        (mod (+ my/current-theme-index direction) (length my/doom-themes-list)))
  (my/apply-theme (my/theme-at-index)))

(defhydra hydra-themes (:hint nil)
  "
^Theme Gallery^
-------------------------------
_n_ Next  _p_ Previous
_o_ Open Gallery _u_ Update Gallery
_RET_ Save
_q_ Quit
"
  ("n" (my/rotate-theme +1))
  ("p" (my/rotate-theme -1))
  ("o" (my/theme-gallery-split-html) :exit t)
  ("u" (my/generate-gallery-screenshot-script) :exit t)
  ("RET" (my/save-theme doom-theme) :exit t)
  ("q" nil "Quit"))
#+end_src
