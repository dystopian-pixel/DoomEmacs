* Tangle on Save

Here the file takes care of housekeeping when you save your work. It keeps derived outputs in sync so you don’t have to remember to run extra steps. The emphasis is reliability and repeatability. You focus on writing; the system quietly handles the rest.

#+begin_src emacs-lisp
(defun my/tangle-on-save ()
  "Tangle Org files before saving."
  (when (and buffer-file-name
             (string-match-p "\\.org$" buffer-file-name)
             (string-prefix-p (expand-file-name "~/.doom.d/") buffer-file-name))
    (org-babel-tangle)))
(add-hook 'before-save-hook #'my/tangle-on-save)
#+end_src
