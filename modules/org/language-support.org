* Language Support Configuration

This section defines how the editor understands and adapts to different programming languages. It focuses on consistency, comfort, and clear feedback so each language feels welcoming rather than fussy. The goal is to provide sensible defaults that reduce setup time and cognitive load. You get a calm, predictable foundation that scales from tiny scripts to larger projects.

** Python Mode

This subsection shapes a pleasant writing environment for Python. It aims for readable text, gentle guidance, and small conveniences that keep you moving. The focus is on clarity and rhythm so you can concentrate on ideas instead of mechanics. You open a file and the surroundings simply help you think.

#+begin_src emacs-lisp
;;; language-support.el --- Python -*- lexical-binding: t; -*-

(use-package! python
  :mode ("\\.py\\'" . python-mode)
  :config
  (setq python-shell-interpreter "python3"))
#+end_src

** LSP Pyright

This subsection emphasizes timely, understandable feedback while you work with Python. It keeps suggestions and notices readable, nudging you toward clarity without interrupting your flow. The tone is supportive rather than noisy, highlighting what matters and fading into the background when you’re in the zone. The result is steadier momentum and fewer surprises as your code evolves.

#+begin_src emacs-lisp
(use-package! lsp-pyright
  :hook (python-mode . lsp!))
#+end_src

** Prefer classic C and C++ modes for now

This keeps C and C++ on the classic major modes until the current Tree-sitter font-lock issue is out of the way. It also makes Doom's built-in file templates and snippets line up with the modes that new C and C++ files actually open in.

#+begin_src emacs-lisp
(with-eval-after-load 'cc-mode
  ;; Prefer classic modes for C/C++ file extensions.
  (dolist (entry '(("\\.c\\'"   . c-mode)
                   ("\\.h\\'"   . c-or-c++-mode)
                   ("\\.cc\\'"  . c++-mode)
                   ("\\.cp\\'"  . c++-mode)
                   ("\\.cpp\\'" . c++-mode)
                   ("\\.cxx\\'" . c++-mode)
                   ("\\.hh\\'"  . c++-mode)
                   ("\\.hpp\\'" . c++-mode)
                   ("\\.hxx\\'" . c++-mode)))
    (add-to-list 'auto-mode-alist entry))

  ;; Defuse tree-sitter remapping for the C family in this config.
  (setq major-mode-remap-alist
        (assq-delete-all 'c-mode major-mode-remap-alist))
  (setq major-mode-remap-alist
        (assq-delete-all 'c++-mode major-mode-remap-alist))
  (when (boundp 'major-mode-remap-defaults)
    (setq major-mode-remap-defaults
          (assq-delete-all 'c-mode major-mode-remap-defaults))
    (setq major-mode-remap-defaults
          (assq-delete-all 'c++-mode major-mode-remap-defaults))))
#+end_src
